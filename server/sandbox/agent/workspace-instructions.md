# 智标智能体工作区

当前工作目录 `/workspace` 是本次任务的工作区，由平台准备。输入材料、过程文件和结果文件均按任务约定在该目录内读取或保存。

可用命令：rg、fd、jq、node、ls、cat、pwd、head、tail、wc、sort、uniq、mkdir、cp、mv、rm、touch、basename、dirname、realpath、cut、tr、du、stat、grep、find、sed。

专用工具以本次会话提供的工具列表为准，未提供的工具不要调用。

约定：

- 只读写当前工作区内的文件。不要访问当前工作区外的路径；`/tmp` 只用于临时文件，其中的内容不会保存。
- 当前环境没有外部网络。不要通过命令、脚本或自行构造请求访问网络；任务明确提供的专用工具可按其说明调用。
- 用户任务中指定的工具和操作步骤通常是推荐路径，不构成工具使用限制。优先采用推荐路径；当其不适用、执行受阻，或有更高效可靠的方法时，可以自主选择其他可用工具完成任务。处理较大材料时，可按需检索、分段读取、编写本地脚本，并保存临时文件和工作笔记。避免重复检查、无目的试探和重复实现已有工具能力。工具选择可以调整，但必须满足任务目标、结果格式和明确的内容保留要求。
- 需要输出结果时，严格写入任务要求的输出文件。
- 不得虚构工具执行结果、文件存在状态或任务完成情况。禁止生成没有实际依据的引用。
- 程序写入的输入资料和不属于本次任务的文件不要修改。`pi-sessions` 目录由程序使用，不要读取、修改或删除其中的文件。

## 文件命名与保存

工作区中的文件在任务结束或暂停时由程序取回保存，取回时逐项检查。只要有一个文件不符合下列规则，本次工作区就无法保存：

- 只建普通文件和目录，不要创建符号链接、硬链接或其他特殊文件；
- 文件名和目录名只使用汉字、英文字母、数字和 `.`、`_`、`-`、`(`、`)`，以及中文的（）【】《》、·；第一个字符必须是汉字、字母、数字或（【《；不要使用空格和其他符号；
- 每一级名称不超过 100 个字节（约 33 个汉字），完整路径不超过 255 个字节，路径最多 8 级（含文件名）；
- 文件扩展名只能是 md、txt、json、jsonl、html、mmd、svg、csv、png、jpg、jpeg、gif、webp；
- 文件总数不超过 10,000 个，总大小不超过 512 MiB，单个文件不超过 100 MiB。

不再需要的临时文件放在 `/tmp` 或及时删除。

## 大文件与大量结果处理

- 任务要求“完整阅读、全部处理、输出完整结果”时，完整性指最终覆盖范围，允许通过多轮读取、处理和写入完成。
- 根据材料大小和结构，自主选择整文件读取、范围读取或检索。需要全文覆盖时，分批处理并跟踪已完成与未完成范围；不能用少量检索结果代替全文处理。
- 每批完成后及时保存结果，避免先读完全部大文件再开始工作。进度和必要结论保存在任务允许的文件中，保留原文位置供后续核对。
- 大量内容通过多轮 write/edit 逐步生成，保持任务要求的文件格式，不反复重写或回读未变化的完整结果。
- 批次大小根据内容复杂度和工具反馈调整，兼顾上下文占用与调用次数，不机械地切成大量极小批次。
- 工具结果被截断时，按范围继续获取缺失部分。上下文压缩后，从已保存的结果和进度继续，不重复已完成工作。

## 当前运行环境

- 当前操作系统为 Linux，bash 工具实际使用 `/bin/sh`（dash），不是 bash：使用 POSIX Shell 语法，不要使用 `[[ ]]`、数组、`{a,b}` 展开等 bash 专有写法。
- 为包含空格或中文的路径加引号；文本文件统一按 UTF-8 处理。
- 每条命令最多运行 5 分钟，超时会被终止；耗时较长的处理拆成多条命令分步执行。
