# ZhiBiaoTools (智标投标工具箱)

A desktop tool for writing bid documents. This repository is converting the desktop client into a web service; see [docs/MIGRATION_PLAN.md](docs/MIGRATION_PLAN.md) for progress.

## Features

- Tender document parsing, technical proposal outline and body generation, expansion of existing proposals
- AI image generation, Mermaid and HTML chart rendering, Word export
- Document knowledge base, credential library, export template settings
- Duplicate checking across bids, disqualification-item checking, typo and logic checks
- Feasibility study report generation

Model services are configured by the user: OpenAI-compatible APIs (including local models via Ollama, LM Studio, etc.), MinerU document parsing and ComfyUI image generation. The app ships with no default model service and contains no analytics.

## Local Development

The desktop client lives in `client/`. Node.js 22 is recommended; debugging Open XML features or packaging locally also requires the .NET 10 SDK.

```powershell
cd client
npm ci
npm run dev         # start Vite and Electron
npm run build       # TypeScript check and Vite build
npm run dist:win    # Windows x64 installer and ZIP
npm run dist:mac    # macOS Intel / Apple Silicon DMG and ZIP
```

Build output goes to `client/release/`. This repository currently has no release process and does not distribute installers.

See [AGENTS.md](AGENTS.md) and [client/开发说明.md](client/开发说明.md) for development conventions, and [docs/EXTERNAL_SERVICES.md](docs/EXTERNAL_SERVICES.md) for the status of external services.

## Architecture

- **Desktop**: Electron Main / Preload provide local capabilities; the Renderer calls them through `window.yibiao`
- **UI**: Vite + React + TypeScript with global CSS and Radix UI
- **Data and tasks**: configuration in a local file, business state in SQLite; long-running tasks run in Main and can resume
- **AI and Agent**: an AI service manages all model requests; Pi Agent runs agent tasks in its own runtime / session
- **Documents**: local or MinerU parsing, Word generated by the .NET Open XML helper, charts rendered locally
